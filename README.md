# 🎓 Multi-Face Attendance System
### Powered by InsightFace (ArcFace) — ~99% Recognition Accuracy

An AI-powered automated attendance system that uses a webcam to detect and recognize multiple student faces simultaneously, then logs their attendance to a CSV file with optional email notifications.

## ✨ Features

- 🔍 **Multi-face detection** — recognizes multiple students at once in a single frame
- 🧠 **ArcFace AI model** — state-of-the-art ~96–99% accuracy (InsightFace `buffalo_sc`)
- 📊 **Auto attendance logging** — writes to `attendance.csv` (one entry per student per day)
- 📧 **Email alerts** — sends confirmation email to each recognized student (optional)
- 📉 **Attendance percentage** — warns if a student drops below 75% attendance
- 📸 **Screenshot** — save any frame with the `S` key
- 🔄 **Hot-reload** — update face encodings without restarting (`R` key)
- ⚡ **Frame-skip optimization** — smooth real-time video even on CPU-only machines

## 🚀 Quick Start (Windows)

> **This is the easiest way.** Just double-click the batch files.

### Step 1 — First-time setup
Double-click **`setup.bat`**
- Creates a Python virtual environment
- Installs all dependencies automatically
- Downloads the AI model (~30 MB, first run only)

### Step 2 — Encode student faces
After adding student photos to the `dataset/` folder, double-click **`encode.bat`** (or run it from `run.bat` menu).

### Step 3 — Start the system
Double-click **`run.bat`** → choose an option from the menu.

## 🛠️ Manual Setup

If you prefer the command line:

```bash
# 1. Create a virtual environment
python -m venv .venv

# 2. Activate it
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 3. Install dependencies
pip install -r requirements.txt

# 4. Encode student faces (run once, or when you add new students)
python encode_faces.py

# 5. Start the live attendance system
python main.py
```

## 👤 Adding New Students

1. Create a new folder inside `dataset/` named after the student  
   Example: `dataset\John\`
2. Add **10–20 clear face photos** (JPG, PNG, or BMP) of that student  
   - Face should be clearly visible
   - Variety of angles / lighting is better
3. Add their email to `student_details.csv`:
   ```
   Name,Email
   John,john@example.com
   ```
4. Run `encode_faces.py` again (or press **R** while the system is running)

## ⚙️ Configuration

Open `main.py` and edit these values near the top:

| Variable | Default | Description |
|---|---|---|
| `DATASET_PATH` | `dataset/` | Path to student images folder |
| `TOTAL_WORKING_DAYS` | `30` | Used for attendance % calculation |
| `RECOGNITION_THRESHOLD` | `0.40` | Matching strictness (lower = stricter) |
| `SENDER_EMAIL` | your email | Gmail address for sending alerts |
| `SENDER_PASSWORD` | `""` | Gmail [App Password](https://myaccount.google.com/apppasswords) |
| `FRAME_SKIP` | `2` | Process every Nth frame (1=max accuracy, 3=faster) |
| `DISPLAY_WIDTH` | `960` | Output window width in pixels |

> **Note:** To enable email alerts, you need a Gmail App Password (not your normal Gmail password).  
> Generate one at: https://myaccount.google.com/apppasswords

## 🧠 How It Works

```
Webcam Frame
     │
     ▼
InsightFace Detector (buffalo_sc)
     │  detects all faces in frame
     ▼
ArcFace Embedding (512-dim vector per face)
     │  normalized cosine comparison
     ▼
Match against face_encodings.pkl
     │  threshold: 0.40 cosine distance
     ▼
Known Face → Mark Attendance + Email
     │
     ▼
attendance.csv  (Name, Date, Time)
```

1. **`encode_faces.py`** scans every image in `dataset/`, extracts a 512-dimensional ArcFace embedding for each face, and saves all embeddings to `face_encodings.pkl`.
2. **`main.py`** opens the webcam, runs InsightFace on each frame, computes the cosine distance between the live face embedding and all stored embeddings, and marks attendance if the distance is below the threshold.
3. Each student is only marked once per day (checked against both the in-session set and the CSV file).

## 🔧 Troubleshooting

| Problem | Solution |
|---|---|
| `face_encodings.pkl not found` | Run `python encode_faces.py` first |
| Camera not opening | Check webcam connection; try changing `cv2.VideoCapture(0)` to `1` |
| Faces not recognized | Lower `RECOGNITION_THRESHOLD` to `0.35`; add more varied photos |
| Slow performance | Increase `FRAME_SKIP` to `3` or `4` |
| Email not sending | Generate a Gmail App Password and set `SENDER_PASSWORD` |
| Model download fails | Check internet connection; first run downloads ~30 MB |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` inside the virtual environment |
